# 수동 QA 시나리오

작성: 2026-04-30
실행: 사람이 브라우저(또는 앱인토스 시뮬레이터)에서 따라하면 됨.

---

## 시나리오 1 — 첫 실행 (신규 유저)

**전제**: localStorage 비어있음 (시크릿 창 권장)

1. `npm run dev` 후 브라우저로 접속
2. 로딩 splash 0.2초 후 인트로 컷씬 자동 시작
3. 3장면 자동 진행 (각 1.8초) — dot 진행도 확인
4. 마지막 장면 자동 종료 또는 화면 탭 시 즉시 스킵
5. 타이틀 화면 진입 — 로고 / "그대는 봉인된 마왕..." / 챕터 1 진행 박스 확인
6. ⚔ 전투 시작 클릭

**기대**: 6단계 모두 정상 동작. 인트로 닫히면 다음 진입 시 재노출 안 됨.

---

## 시나리오 2 — 첫 런

1. 게임 진입 시 마왕성(좌) + 적 진영 깃발(우) 시각 분리 확인
2. 시작 마력 200 표시 / "🔮 카드 펼치기 50 마력" (첫 3회 할인) 확인
3. 카드 펼치기 클릭 → 봉인 깨기 1.1초 → 카드 3장 등장
4. 카드 1장 픽 → 몬스터 등장 + "✨ {이름} 등장 ✨" 배너 + 황금 flash
5. 2.5초 후 "💡 마력은 자동 회복" toast
6. 적 hero 1.6초 후 등장 → 자동 전투
7. 마력 회복 (3.5/sec) → 두 번째 카드 펼치기
8. 같은 종 카드 3장 픽 → 진화 발동 (slowmo + banner)
9. 첫 시너지 활성 시 풀모달 "🌀 시너지 시스템" 안내
10. 웨이브 5 도달 → 보스 등장 (▼ 화살표 + 캐릭터 대사)
11. 보스 처치 → 신규 유저 자동 +30% HP 회복

**기대**: 11단계 모두 정상. 막히는 지점 없음.

---

## 시나리오 3 — 실패 / 결과

1. 일부러 마왕성 HP 0까지 깎기 (Rally 안 쓰고 카드 안 픽)
2. (runs >= 3인 경우) 부활 광고 모달 노출 / 거절
3. ResultScreen 진입 (BGM 400ms fade)
4. 신기록 시 "NEW RECORD / 웨이브 N / +X" 황금 박스 확인
5. 첫 사망(runs===1) 시 "💡 첫 강화 추천" 카드 우선 노출
6. "⚔ 다시 도전" 무한 펄스 확인
7. 다시 도전 1탭 → GameScreen 즉시 재진입

**기대**: 모든 단계 정상. 영혼석 보상 정상 적립.

---

## 시나리오 4 — 저장/로드

1. 게임 진행 (웨이브 3까지)
2. 일부러 일시정지 → "포기하고 나가기" → 결과 화면
3. **F5 새로고침** (또는 탭 닫고 다시 열기)
4. localStorage 정상 유지 확인
5. 타이틀 — bestWave / 영혼석 / runs 모두 보존
6. **개발자 도구 → localStorage → maowang-save-v4 키를 의도적으로 손상 (예: "soulstones": "abc")**
7. 새로고침 → migrate가 비정상 값 복구 → 게임 정상 진입
8. console에 `[saveStore] rehydrate 실패` 경고 가능 (정상)

**기대**: 손상 데이터에서도 앱 죽지 않음. 기본값 복구.

---

## 시나리오 5 — 메뉴 화면 전환

1. 타이틀에서 영혼 강화 → 트리 3개 색조(파랑/녹/빨강) 차등 + 추천 스킬 황금 펄스 (ResultScreen에서 진입 시)
2. 5런 도달 후 타이틀 → 추가 메뉴 해금 (도감/업적/리더보드/상점/일일 미션/도전)
3. 상점 → 5종 SKU 표시 / 보유 중 표시 / 확정 상품 안내
4. 도감 → 가이드 탭 → 슬라임/마법/언데드 빌드 가이드 확인
5. 일시정지 메뉴 → 화면 흔들림 OFF / 햅틱 OFF 토글 → 다시 게임 진행 시 적용 확인
6. 모든 화면 우측 상단 또는 하단 닫기/돌아가기 버튼으로 타이틀 복귀

**기대**: 모든 화면 진입/종료 정상.

---

## 시나리오 6 — 정책 리스크 검증

1. 모든 화면 텍스트를 천천히 스크롤하며 확인:
   - "슬롯", "릴", "스핀", "잭팟", "777", "당첨", "대박", "배팅", "배당", "페이라인", "카지노", "코인 투입" — **0건이어야 함**
2. 카드 펼치기 시각 연출 확인:
   - 회전 릴 X / 카드 봉인 깨기 + 뒤집기 ✓
3. 결과 화면 보상:
   - "현금" / "환전" / "상금" 표현 0건
4. 광고 버튼:
   - "광고 보고 영혼석 ×2" — 자발적 + 거절 가능
   - "광고 보고 부활" — 1런당 1회 + 거절 가능
5. IAP 상품:
   - 5종 모두 확정형 (랜덤 박스 X)

**기대**: 모든 항목 안전.
