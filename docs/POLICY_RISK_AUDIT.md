## 1. 금지어 검색 결과 (사용자 노출 텍스트)

검색 도구: `grep -r` 한국어/영어 양쪽

| 금지어 | UI 노출 | 코드 주석 | 조치 |
|---|---|---|---|
| 슬롯 / slot | 0건 | 8건 (주석) → 모두 "카드 공개"로 정리 | ✅ 안전 |
| 릴 / reel | 0건 | 0건 | ✅ 안전 |
| 스핀 / spin | 0건 | 0건 | ✅ 안전 (사용자 노출). 내부 변수 `spinChoices`/`spinCount`/`beginSpin` 등 잔존 — 코드 식별자만 |
| 잭팟 / jackpot | 0건 | 잔존 (주석/내부) — 라벨은 "✨ 희귀 발견"으로 변경됨 | ✅ 안전 |
| 777 | 0건 | 픽셀 그리드 색상 인덱스 `'77777.77777'` 잔존 (도박 표현 아님) | ✅ 안전 |
| 당첨 / 대박 / 배팅 / 배당 / 페이라인 / 카지노 | 0건 | 0건 | ✅ 안전 |
| coin insert / 코인 투입 | 0건 | 0건 | ✅ 안전 |

**결론**: 사용자 노출 텍스트에서 금지어 0건. 코드 주석은 모두 안전한 한국어로 정리.

|---|---|---|---|

| 유물 선택 | "랜덤 박스" | "유물 선택" 풀모달 — 3개 카드 중 1개 명시적 선택 | ✅ 안전 |

## 3. 광고 보상 구조 검토

- **결과 화면 영혼석 ×2 광고**: ✅ 자발적, 거절 가능
- **부활 광고**: ✅ 1런당 1회 / 거절 가능 / 첫 3런 노출 안 함
- **인터스티셜 광고**: ✅ 광고 제거 IAP 미구매 + runs >= 4 + 50% 확률만
- **첫 3세션 광고 없음**: ✅ "✨ 신규 환영 — 첫 3런까지 광고 없음" 명시

## 5. 검수 리스크 종합 판단

| 항목 | 상태 |
|---|---|
| 슬롯/릴/스핀 시각 연출 | ✅ 제거됨 (회전 릴 X / 카드 뒤집기 + 봉인 깨기 연출) |
| 도박/베팅 용어 | ✅ 0건 |
| 유료 랜덤 보상 | ✅ 없음 |
| 현금성 가치 표현 | ✅ "영혼석 / 유물 파편 / 별가루" — 비현금성 게임 자원 |
| 환전/상금 표현 | ✅ 없음 |
| 광고 보상 강제성 | ✅ 모두 자발적 |
| 첫 3세션 광고 면제 | ✅ 적용됨 |
| 확률형 아이템 고지 의무 | ⚠ 카드 펼치기 풀 가중치는 monsters.ts에 코드로 명시 (별도 확률 페이지 권장) |
