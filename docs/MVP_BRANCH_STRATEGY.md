# MVP Branch Strategy

`main` is the clean React/Vite baseline. Keep it buildable and small.

Archived prototype:

- `archive/ai-prototype`

MVP branches should be small and mergeable:

1. `mvp/01-shell`
2. `mvp/02-canvas-battlefield`
3. `mvp/03-card-summon-loop`
4. `mvp/04-wave-combat`
5. `mvp/05-progression`

Rule: merge only working, reviewable slices into `main`.
