# 마왕 디펜스 — 작품성/게임성 고도화 마스터 플랜

> 현재 상태: 기능 완성된 60+ QA 패치 빌드. 코어 루프 작동, 그러나 단조롭고 차별점 약함.
> 목표: **카이로 감성 + 게임성 극대화**. 출시 가능한 "한 판 더" 중독성 확보.
>
> 에셋은 후순위. 데이터·시스템·연출 단계에서 끌어올릴 수 있는 것부터.

## 1. 진단 — 왜 게임성이 약하게 느껴지는가

### 1.1 의사결정의 깊이 부족
- 사용자 의사결정 = "3장 카드 중 1장 픽" + "유물 3 중 1" 둘뿐
- 카드 픽이 14초마다 1번 → 한 판 20분에 ~80회. 그러나 **각 의사결정이 거의 단순 비교** (epic > rare > common)
- 진화/시너지 임박 배지가 사실상 정답을 알려줌 → 사용자 사고 과정 생략

### 1.2 빌드 다양성 표면적
- 시너지 8종 = 태그 일치만 보면 됨. 빌드 컨셉이 "마법 빌드 / 언데드 빌드" 4~5개 안에서 수렴
- 유물 30종 효과가 +20%/×0.7 같은 수치 보정 위주. **플레이 스타일 변화 X**
- 결과: 매 런 같은 결정 트리

### 1.3 컨텐츠 단조로움
- W1~W100 같은 화면 (LD-D로 색조만 바뀜)
- 보스 5종 후 무한 사이클 — 신화 이상은 패턴 동일
- 인테리어/꾸미기/세계관 표현 부재

### 1.4 캐릭터·내러티브 약함
- 마왕(주인공) 시각/대사 부재
- 보스 dialog 5문장이 전부
- 시너지/유물 효과가 모두 시스템 텍스트 ("×1.4")

### 1.5 시각적 정체성 약함
- 어두운 보라/빨강 톤이 전부
- 캐릭터 sprite 단순
- "이 게임만의" 시각이 없음

## 2. 카이로 핵심 4요소 적용 (사장냥 GDD에서 도입)

### 2.1 겹겹이 쌓이는 성장 레이어
**현재 마왕 디펜스**: 영혼강화 9종 + 챕터 마일스톤. 평면적.

**도입 방향**:
- **던전 층 시스템** — 각 wave가 독립 "던전 층"이고, 층마다 시각/배경/적 풀/유물 풀 다름
- **마왕 본체 레벨** — 처치 누적으로 마왕 자체 강화 (메타와 별개로 인게임 메타)
- **카드 풀 잠금 해제** — 진행도에 따라 새 1성 카드 풀이 열림 (현재는 10종 고정)

### 2.2 발견의 즐거움
**현재**: tagPickCount 동적 가중치만. 사용자 인지 X.

**도입 방향**:
- **숨겨진 시너지** — 특정 카드 조합(예: 슬라임+위치+미믹)에 비공개 시너지
- **유물 진화** — 유물 2개 조합 시 새 유물 변환 (Slay the Spire boss relic 톤)
- **마왕 비밀 능력** — 특정 행동(50콤보, 풀 매직 빌드 등) 달성 시 영구 마왕 능력 해금

### 2.3 도트 캐릭터의 생명력
**현재**: drawDemonLord 단순 sprite. 보스 5종 dialog 5문장. 손님(적) 무대사.

**도입 방향**:
- **마왕 캐릭터 시스템** — 인게임 화면 좌측 상단 마왕 초상 + 표정 변화 (HP 위급/시너지 발동/보스 등장 시 대사)
- **단골 적 시스템** — 특정 hero(예: archer)와 N번 만나면 "친숙한 얼굴" — 처치 시 sympathetic dialog
- **상점 NPC** — wave 사이 등장, 유물 거래 등

### 2.4 "한 턴만 더" 중독성
**현재**: bestWave 단일 지표. ResultScreen "다시 도전" OK.

**도입 방향**:
- **달성 임박 큐** — ResultScreen에 "다음 강화 92% 진행", "단골 손님 1마리 더 만나면 해금" 등 **항상 N개 임박 표시**
- **조각 수집** — 처치 시 적 도감 조각 누적, 100% 시 영구 보너스
- **데일리 변수** — 매일 1회 "오늘의 모디파이어"로 같은 게임이 다른 룰

## 3. 게임성 극대화 — 6대 핵심 신규 시스템

### 3.1 [P0] 던전 층(Stratum) 시스템 — 컨텐츠 다양성

현재 wave 진행이 일직선이라면, 5wave마다 **던전 층 전환** 도입:

| 층 | wave | 컨셉 | 배경 | 적 풀 | 특수 룰 |
|---|---|---|---|---|---|
| 1층 — 봉인의 입구 | W1~5 | 학습 | 어두운 보라 | 견습기사·검사·궁수·창병 | 기본 |
| 2층 — 잊혀진 묘지 | W6~10 | 언데드 위협 | 무덤 + 안개 | + 마법사·도적 + **언데드 hero(좀비/스켈 변종)** | 적 처치 시 30% 좀비 부활 |
| 3층 — 화염 전당 | W11~15 | 화염 빌드 보상 | 용암 톤 | 적 화상 데미지 + 화염 보스 강화 | 화염 카드 등장률 ↑ |
| 4층 — 광기의 미궁 | W16~20 | RNG 강화 | 보라 + 무지개 잔상 | 랜덤 hero 풀 | 매 wave 모디파이어 1개 |
| 5층 — 신의 영역 | W21~25 | 챕터 1 보스 도달 | 황금 빛 | 성기사·성녀 | 마지막 wave는 boss rush |

각 층 진입 시 **층 전용 banner + 짧은 dialog + 배경 전환 컷씬**. 사용자가 "다음 층 가야지" 동기 강함.

### 3.2 [P0] 카드 의사결정 깊이 — 카드 가중치/페널티 다양화

현재: 카드 3장이 단순 등급/태그 표시. 의사결정 = "더 좋은 등급 픽".

신규:
- **카드 등장 가중치 동적 변화** — 픽 패턴에 따라 다음 풀이 변함 (이미 부분 구현, 사용자 인지 신호 강화)
- **"리스크 카드"** — 강력하지만 리스크 동반 (예: 마력 -50, 적 1명 추가 spawn, 마왕성 -10% 등)
- **"아군 희생 카드"** — 아군 몬스터 1마리 죽이고 epic 1장 즉시 (Slay the Spire 톤)
- **"운명 분기 카드"** — 5wave마다 "분기 카드" 1장 강제 등장 (다음 5wave 빌드 방향 결정: 화염 / 언데드 / 탱커)

### 3.3 [P0] 빌드 컨셉 시스템 — 캐릭터 직업 같은 명확한 정체성

현재: 시너지 8종이 모호하게 빌드 정의.

신규: **빌드 컨셉 9종** 명시 (Slay the Spire 캐릭터 / Hades aspect 톤):

| 빌드 | 핵심 카드 | 핵심 유물 | 메인 컨셉 |
|---|---|---|---|
| 좀비 군단 | zombie 라인 | tomb·serpent | 죽지 않는 물량 |
| 화염 폭주 | imp/devil/dwitch | inferno·crown | 광역 + DOT |
| 마법 학파 | witch/lich | oracle·crown | 원거리 폭딜 |
| 슬라임 왕국 | slime 진화 | swarm·iron | 탱킹 + 수량 |
| 언데드 군주 | skel·zombie·lich | bloodmoon·tomb | 부활 + 시너지 |
| 야수의 분노 | orc·beast | wrath·sprint·razor | 빠른 처치 |
| 어둠 신비주의 | dark 태그 | abyss·hex | 어둠 시너지 |
| 탐욕의 길 | mimic·gmimic | greed·vault | 자원 가속 |
| 폭군의 일격 | 필살기 중심 | crown·oracle | 한방 빌드 |

각 빌드는 **달성 조건 + 시각 칭호 + 영구 해금 보상**. 사용자가 "이번 런은 좀비 군단 도전" 명확한 목표.

### 3.4 [P0] 마왕 캐릭터 시스템 — 내러티브 + 시각적 매력

현재: 마왕성(건물)만 있음. 마왕 본인 부재.

신규:
- **인게임 화면 좌측 상단**에 마왕 초상 (32×32 head bust) — 표정 4종(평온/위급/분노/승리)
- **상황별 마왕 대사** — 마왕성 위급/보스 등장/시너지 발동/진화/페이즈 2/사망 직전 등 ~30종
- **마왕 강화 시스템** — 누적 보스 처치 / 챕터 클리어로 마왕 자체 능력 영구 해금 (별도 메타)
- **마왕 외형 변화** — 챕터 1/2/3 클리어마다 마왕 초상 시각 변화 (왕관 / 갑옷 / 신화)

### 3.5 [P1] 적 도감 + 조각 수집 — 카이로 발견 재미

현재: 도감은 단순 컬렉션, C-3에서 5/10/15/20 도달 시 영혼석만 보상.

신규:
- 적 처치 시 **조각 1개 누적** (spliner system)
- 100조각 채우면 **해당 적의 영구 약화 효과** 영혼강화처럼 적용 (그 적이 매 wave +10% 약함)
- 도감에 캐릭터 카드 + 짧은 lore + 처치 누적 + 조각 게이지 표시
- 카이로 "도감 페이지 채우기" 감성

### 3.6 [P1] 일일 변수 시스템 — 매 런 새로움

현재: 매 런 같은 변수.

신규:
- **매일 1회 "오늘의 칙령"** — 5종 모디파이어 중 하나 무작위:
  - "어둠의 시간": 다크 시너지 ×2
  - "약자의 심판": 모든 적 HP -20%, 마왕성 HP -30%
  - "황금 비": 영혼석 +50%, 적 ATK +30%
  - "부활의 밤": tomb 유물 자동 보유, 진화 조건 4
  - "운명의 변동": 카드 reroll 무제한
- 적용된 런은 결과 화면에서 별표 + 영혼석 +20%
