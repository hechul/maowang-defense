# 첫 3분 UX 리뷰

작성: 2026-04-30 (자동 시뮬레이션)

## 0~5초: 인트로 컷씬
- IntroCutscene 자동 노출 (runs===0, tutorialSeen에 'intro' 미포함)
- 3장면 × 1.8초 = 5.4초 / 탭하여 스킵
- "천 년의 봉인이 풀렸다 → 인간 왕국의 용사들이 → 운명의 카드를 펼쳐 어둠을 소환하라"
- 진행도 dot 3개 — 다음 장면 예측 가능

## 5~10초: 타이틀 화면
- 로고 PNG (`logo_main.png`)
- 게임 설명 3줄: "그대는 봉인된 마왕 / 용사들이 마왕성으로 / 운명의 카드로 어둠을 소환해 영토를 지켜라"
- 챕터 진행 박스 (현재 챕터 1, 0/25)
- "⚔ 전투 시작" 빨간 큰 버튼 (primary)
- 신규 유저 메뉴는 "전투 시작 + 영혼 강화"만 (잠금: 5런 도달 시 추가 해금 0/5)

→ **1탭 = 게임 진입**

## 10~25초: 첫 게임 화면 + 카드 펼치기
- GameScreen 마운트 시 마왕성(좌) + 적 진영(우 깃발)
- 시작 마력 200 / 첫 3회 카드 펼치기 50 마력
- "👆 탭=돌격 / 장탭=어둠의 손(30 마력)" 안내 텍스트
- "↓ 운명의 카드를 펼쳐 몬스터를 소환하세요 ↓" FTUE 펄스
- 카드 역할 범례 (🛡 탱커 / ⚔ 근거리 / 🏹 원거리 / 🔮 마법) 4-칩

## 25~30초: 첫 카드 픽
- 카드 펼치기 → 봉인 깨기 1.1초 (face-down 카드 펄스)
- 카드 3장 flip 등장 (legendary 등급은 큰 사이즈 + 흔들림)
- 카드 본문: 역할 / 이름 / HP / ATK / 별 / (필요 시) 진화 임박 / 시너지 임박
- 첫 카드 픽 후 "💡 같은 카드 3장을 모으면 진화" toast

## 30초~1분: 첫 와 모먼트
- 첫 몬스터 등장 시 큰 banner "✨ {몬스터명} 등장 ✨ — 용사를 막아라!"
- 화면 황금 flash + shake 10
- 2.5초 후 "💡 마력은 자동 회복" toast

## 1~2분: 첫 진화 / 첫 시너지
- 같은 몬스터 3장 픽 → 진화 발동 시 풀모달 "🌀 시너지 시스템 / 좌상단 🌀 칩 탭" 안내
- 진화 발동 시 banner + slowmo 0.4초 + 황금 flash

## 2~3분: 첫 보스 (웨이브 5)
- 빨간 flash + 18 shake + slowmo 0.5초
- 보스 위 ▼ "보스" 라벨 4초 펄스
- 보스 캐릭터 대사 banner: "어둠의 군주여, 너의 시대는 끝났다!"
- 첫 보스 (기사단장) HP 400 → 4~5초 처치 가능
- 처치 시 신규 유저 (runs<5) 자동 +30% HP 회복

## 첫 실패 (예상 웨이브 6~10)
- ResultScreen 진입 (BGM 400ms 단축 fade)
- 신기록 시 "NEW RECORD / 웨이브 N / 이전 N → +X" 황금 박스
- 첫 사망 (runs===1) 시 "💡 첫 강화 추천 (50% 할인 중!)" 카드 우선
- "⚔ 다시 도전" 무한 펄스 (재도전 동기 강화)
- 다음 목표 4단계 (현재 wave에 따라 동적)

## 막힐 가능성 / 대응

| 시점 | 막힐 이유 | 자동 대응 |
|---|---|---|
| 첫 진입 인트로 | 5초 답답 | 탭 스킵 가능, dot 진행도 표시 |
| 첫 카드 펼치기 | 안 누름 | FTUE 펄스 + 화살표 + 카드 역할 범례 |
| 첫 진화 | 운으로 안 나옴 | 같은 카드 픽 시 "진화 X/N (살아있는)" 진행도 표시 |
| 첫 시너지 | 효과 모름 | 발동 시 풀모달 학습 — "탭 = 자세히" |
| 첫 보스 | 너무 어려움 | HP 600→400 / invuln 정의 X (첫 보스만) |
| 마력 부족 위급 | 무대응 | HP<30% + 마력부족 시 무료 카드 펼치기 1회 |
| 광고 시청 실패 | 즉시 종료 | RevivalModal "다시 시도" 버튼 |
| 첫 사망 좌절 | 영혼석 0 | 신규 5런 영혼석 +50 보너스 + 첫 강화 50% 할인 |

## 종합 판정: 🟢 양호

신규 유저가 **3분 안에 카드 펼치기 → 진화 → 보스 → 결과 화면**까지 도달 가능. 첫 5런 보호 장치 다중 적용.

**여전히 개선 여지 (P2)**:
- 첫 1분 안에 "선택의 결과"가 전투 결과로 명확히 연결되는지 시각 강화
- 진화 학습이 운에 의존 — 첫 픽 후 두 번째 슬롯에 같은 종 강제 등장 (P2 검토)
