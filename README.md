# Maowang Defense

Clean React/Vite baseline for rebuilding the Maowang Defense MVP.

The original AI-generated prototype is preserved on:

```bash
git switch archive/ai-prototype
```

This `main` branch should stay small, buildable, and easy to understand. MVP features will be added through focused branches and merged back one by one.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```
